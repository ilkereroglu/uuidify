# Contributing Guidelines

Thank you for contributing to **UUIDify**!

Please follow these rules for consistency and quality:

- Use [Conventional Commits](https://www.conventionalcommits.org/).
- Open an issue before starting a new feature.
- Run `make test` before submitting a pull request.
- Ensure code passes `make lint` and builds successfully.
- Keep PRs small and focused.
- PR titles should follow the pattern: `feat(scope): short description`.

We appreciate your time and help in making UUIDify better! 🚀
